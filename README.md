# 🎵 bro Music App

A retro-themed music player built with Flutter. Designed to give users a nostalgic experience with modern functionality.

## ✨ Features

- 🎨 style UI and custom app icon
- 📻 Play local and online music
- 📀 Custom-designed vinyl record app icon
- ▶️ Play/Pause control
- 📜 Playlist display
- 📱 Responsive design
